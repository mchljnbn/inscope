Inscope

Instagram data viewer · Go + Python backend · Flutter client

Pre-launch — GitHub release pending

What it does

Inscope reads public Instagram profile, post, comment and search data without an official API. Follower/following lists require a logged-in session, so the app sends your own session per request — it is used in memory only and never written to the backend's database or disk. There is no shared or "helper" account, and no user can use another user's session.

Because Instagram removed chronological follow order in 2026, Inscope reconstructs new follows by taking dated snapshots and merging the ranked subsets Instagram actually serves. Detection time is not exact follow time.

Privacy & optional monetization

Inscope is free and works fully with all optional features off. An optional, opt-in Honeygain integration may be offered in a private build. If enabled, it shares a small amount of unused internet bandwidth and allows Honeygain to create exit nodes through end users' devices. It does not access personal data, files, messages, or browsing history. Users must explicitly accept a consent screen and can opt out at any time in Settings. Sharing may increase Instagram rate limits on the same device.
